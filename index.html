Part 1: What Is a List?

👉 INSTRUCTION: Read the explanation, then complete Task 1.

So far, each variable you have used holds one value. But what if you need to store 30 colours, or 100 test scores? Making 100 separate variables would be slow, and you could not loop through them.

A list solves this. It is one variable that holds many values, in order. You write the items inside square brackets, with commas between them.

colours = ["red", "green", "blue", "yellow"]
ages = [15, 16, 16, 17]
mixed = ["Ali", 16, True]      # a list can hold different types
💡 Think of a list like a row of numbered lockers. Each locker holds one item, and each locker has a number. Just like strings, the numbers start at 0.
Item"red""green""blue""yellow"
Index0123
Negative index-4-3-2-1

To get one item, write the list name and the index in square brackets. len() tells you how many items there are.

print(colours[0])      # red     (the first item)
print(colours[2])      # blue
print(colours[-1])     # yellow  (-1 always means the last item)
print(len(colours))    # 4

Asking for an index that does not exist, such as colours[4], causes an IndexError.

📌 Exam word: array. Python has no separate "array" type. When a question says array, it means a list where every item is the same type, e.g. ages above.

Part 2: Changing a List

👉 INSTRUCTION: Read the table, guess the output of the sandbox code, then complete Task 2.

Unlike a string, a list can be changed after you make it. You can add items, swap items and remove items.

CodeWhat it does
songs.append("Echoes")Adds an item to the end of the list
songs.insert(0, "Warm Up")Adds an item at index 0. Everything after it moves along one place.
songs[2] = "Skyline (Live)"Replaces the item at index 2 with a new value
last = songs.pop()Removes the last item and hands it back, so you can store it
first = songs.pop(0)Removes the item at index 0 and hands it back
del songs[1]Deletes the item at index 1 (nothing is handed back)

Step by step: watch the list change after each line.

songs = ["Intro", "Skyline", "Rainfall"]
songs.append("Echoes")         # ['Intro', 'Skyline', 'Rainfall', 'Echoes']
songs.insert(0, "Warm Up")     # ['Warm Up', 'Intro', 'Skyline', 'Rainfall', 'Echoes']
songs[2] = "Skyline (Live)"    # ['Warm Up', 'Intro', 'Skyline (Live)', 'Rainfall', 'Echoes']
last = songs.pop()             # last is 'Echoes'
first = songs.pop(0)           # first is 'Warm Up'
del songs[1]                   # ['Intro', 'Rainfall']
💡 Index numbers move! After an insert() or a removal, the items after it shift along, so their index numbers change. Trace carefully, one line at a time.

After append the list is [5, 10, 15, 20]. After insert(1, 7) it is [5, 7, 10, 15, 20]. Then index 0 becomes 1, and pop() removes the 20.

Part 3: Looping Through a List

👉 INSTRUCTION: Learn the two ways to loop through a list, run the example, then complete Task 3.

To traverse a list means to go through it, visiting every item in turn. A for loop does this for you. There are two ways to write it.

Way 1: loop over the items. Use this when you only need the values.

steps = [6200, 8450, 4300, 10100, 7600]     # steps walked each day
for day_steps in steps:
    print(day_steps)                        # prints each value in turn

Way 2: loop over the index numbers. Use this when you also need the position. range(len(steps)) gives the numbers 0, 1, 2, 3, 4.

for i in range(len(steps)):
    print(f"Day {i + 1}: {steps[i]}")       # Day 1: 6200, Day 2: 8450, ...

Adding up and counting. Create a variable that starts at 0 before the loop, then update it inside the loop.

total = 0
active_days = 0
for day_steps in steps:
    total = total + day_steps               # running total
    if day_steps > 7000:
        active_days = active_days + 1       # counter

print(total)                                # 36650
print(total / len(steps))                   # 7330.0  (the average)
print(active_days)                          # 3

Part 4: 2D Lists (Tables)

👉 INSTRUCTION: Work through steps 1 to 3, guess the output of the sandbox code, then complete Task 4.

Step 1: A list of lists. A list can hold other lists. If each inner list is a row, you get a table. This is called a 2D list (2D means two-dimensional: rows and columns).

This 2D list shows the seats in a tiny cinema. 1 means booked and 0 means free.

seats = [[0, 1, 1, 0],      # row 0
         [1, 1, 0, 0],      # row 1
         [0, 0, 0, 1]]      # row 2
column 0column 1column 2column 3
row 00[0][0]1[0][1]1[0][2]0[0][3]
row 11[1][0]1[1][1]0[1][2]0[1][3]
row 20[2][0]0[2][1]0[2][2]1[2][3]

Step 2: Two indexes: row first, then column.

print(seats[1])         # [1, 1, 0, 0]  one index gives a whole ROW
print(seats[1][2])      # 0             two indexes give ONE seat: row 1, column 2
print(len(seats))       # 3             the number of rows
print(len(seats[0]))    # 4             the number of columns (items in one row)
seats[2][0] = 1         # book the seat at row 2, column 0
💡 Say it out loud: "row, then column". seats[1][2] means "go to row 1, then across to column 2". Every row should have the same number of items.

Step 3: Visit every cell with nested loops. A nested loop is a loop inside a loop. The outer loop picks each row. The inner loop goes across every column in that row.

booked = 0
for row in range(len(seats)):                # row = 0, 1, 2
    for col in range(len(seats[row])):       # col = 0, 1, 2, 3 for each row
        if seats[row][col] == 1:
            booked = booked + 1
print(booked)                                # 5

To build an empty table, use a loop that adds a new row each time:

board = []
for row in range(3):
    board.append([0] * 4)        # [0] * 4 makes a new row: [0, 0, 0, 0]

▶ Show answer 
[0, 0, 0, 1]
1 1
3 4
7

There are 12 seats in total (3 rows × 4 columns). 5 are booked, so 7 are free.

Part 5: Records

👉 INSTRUCTION: Read the explanation and run the example. There is no task here; you will use records in the Pre-Lesson Challenge.

Often you need to store several facts about one thing. For example, a book has an ID, a title and a year. A small list holding these facts is called a record. Each fact is a field.

# fields: [book_id, title, year]
book = [1042, "The Hobbit", 1937]
print(book[1])        # The Hobbit  (field 1 is always the title)

Put many records into one list and you get a list of records. It is just a 2D list where each row is one thing, like a row in a spreadsheet.

# fields: [name, animal, age]
pets = [["Milo", "dog", 4],
        ["Luna", "cat", 2],
        ["Pip", "rabbit", 1]]

for pet in pets:                   # pet is one whole record each time
    print(pet[0], "is a", pet[1])  # Milo is a dog ...
💡 Good habit: write a comment listing the field order, e.g. # fields: [name, animal, age]. Then you always know that pet[2] is the age.

🔮 Run and Explore

This prints the records as a neat table using f-strings. Try adding a fourth pet to the list.

Part 6: Tuples and Converting

👉 INSTRUCTION: Read the explanation, then guess the output of the sandbox code before you run it.

A tuple is like a list, but it uses round brackets and it is immutable: once made, it can never be changed. Use a tuple for data that should stay fixed, such as a colour or a map position.

orange = (255, 128, 0)      # red, green and blue amounts
print(orange[0])            # 255  (indexes work the same as lists)
print(len(orange))          # 3
orange[0] = 200             # TypeError: a tuple cannot be changed
⚠️ A tuple with one item needs a comma. ("x",) is a tuple. Without the comma, ("x") is just the string "x" in brackets.

Converting between types

CodeResultWhat happened

tuple(["a", "b"])('a', 'b')list changed into a tuple
set([3, 3, 4, 4]){3, 4}a set keeps one copy of each value, so duplicates disappear (but the order is not kept)
list("hey")['h', 'e', 'y']a string split into a list of its characters

Part 7: Copying a List Safely

👉 INSTRUCTION: Read the explanation, then run the sandbox and compare the results.

This surprises almost everyone. b = a does not make a copy of a list. It gives the same list a second name. Change one, and you see the change through both names.

a = [1, 2, 3]
b = a              # b is another name for the SAME list
b.append(4)
print(a)           # [1, 2, 3, 4]  a has changed too!

To make a real copy, use the copy library:

  • copy.copy(a) copies the list. This is fine for a simple list.
  • copy.deepcopy(a) also copies every list inside it. Use this for a 2D list.

🔮 Run and Compare

▶ What happened? 
a: [1, 2, 3, 4]  c: [1, 2, 3]
grid: [[99, 2], [3, 4]]
deep: [[1, 2], [3, 4]]

c is a real copy, so it did not change. For the 2D list, copy.copy() copied only the outer list, so both names still share the same rows: changing shallow changed grid too. deepcopy() made fully separate rows.
